# Политика безопасности (Security Policy)

Безопасность пользовательских данных является главным приоритетом проекта SecVault. Если вы обнаружили уязвимость, пожалуйста, следуйте инструкциям ниже.

## Поддерживаемые версии

Патчи безопасности выпускаются только для последней мажорной версии приложения. Использование устаревших версий не рекомендуется.

| Версия | Поддерживается |
| :--- | :--- |
| v0.1.x | :white_check_mark: Да |
| < v0.1.0 | :x: Нет |

## Процесс раскрытия (Disclosure Policy)

**Пожалуйста, не создавайте публичные Issues на GitHub для сообщений об уязвимостях.**

Для приватного раскрытия информации используйте встроенный механизм **GitHub Security Advisories**. 
1. Перейдите во вкладку **Security** в верхней панели репозитория.
2. Нажмите **Advisories** -> **Report a vulnerability**.
3. Опишите проблему, приложите шаги для воспроизведения (PoC) и укажите предполагаемый уровень критичности.

## Сроки реагирования (SLA)

- **Подтверждение получения отчета:** В течение 72 часов.
- **Первичная оценка и план исправления:** В течение 7 дней.
- **Выпуск патча (для критических уязвимостей):** В течение 30 дней с момента подтверждения.

## Вознаграждение

Проект разрабатывается на энтузиазме и не имеет программы Bug Bounty. Однако ваше имя (или никнейм) будет указано в релизе и файле `SECURITY.md` в разделе благодарностей, если вы того пожелаете.
