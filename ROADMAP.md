# Roadmap

План развития проекта. Задачи сгруппированы по версиям в порядке приоритета.

## v0.2.0 - Политика безопасности и доверие

- Создание `SECURITY.md` с контактом для приватного раскрытия уязвимостей (через GitHub Security Advisories).
- Фиксация SLA: подтверждение получения отчета за 72 часа, выпуск патча для критических уязвимостей за 30 дней.
- Настройка подписи релизов (GPG / minisign) и генерация контрольных сумм (checksums) для всех установщиков.
- Добавление в документацию инструкции по проверке подписей перед установкой.

## v0.3.0 - Защита на уровне ОС (Windows)

- Предотвращение сохранения скопированных паролей в системную историю буфера обмена и облачную синхронизацию.
- Блокировка создания дампов памяти (core dumps) ОС при аварийном завершении приложения.
- Запрет на захват окна приложения сторонними инструментами скриншотов и записи экрана.
- Автоматическая блокировка хранилища при системной блокировке рабочей станции (например, Win+L) или отключении сеанса.
- Запрет выгрузки расшифрованных данных в файл подкачки и файл гибернации ОС.

## v0.4.0 - Миграция и интероперабельность

- Импорт данных из KeePass (KDBX), Bitwarden (JSON/CSV), 1Password (1PUX/CSV) и браузеров (Chrome, Edge).
- Обработка дубликатов и ошибок при импорте.
- Экспорт в зашифрованный формат.
- Экспорт в незашифрованный CSV (только при подтверждении пользователя, с автоудалением файла после завершения сессии).

## v0.5.0 - Двухфакторная аутентификация (TOTP)

- Хранение TOTP-секретов и генерация одноразовых кодов внутри хранилища.
- Вывод предупреждения в интерфейсе и документации о том, что хранение TOTP рядом с паролем снижает защиту второго фактора.
